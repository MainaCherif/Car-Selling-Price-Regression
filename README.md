# Car-Selling-Price-Regression
Prédiction du prix de vente d'une voiture d'occasion (en lakhs) à partir du kilométrage, du prix catalogue, du type de carburant, du type de vendeur, de la transmission et de l'âge, en comparant 6 algorithmes de régression : Linear Regression, Ridge, Lasso, Decision Tree, Random Forest (meilleur modèle) et XGBoost.
